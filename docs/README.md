# GitCenter documentation

This directory contains product and feature design documents for GitCenter.

## Feature proposals

- [Contributors widget](contributors-widget.md): repository contributor summaries, activity visualization, and attribution semantics.
- [ZeroID Contributor Registry](zeroid-contributor-registry.md): signed ZeroID declarations associating an identity with a Git commit email, with explicit unverified-email status.

These documents describe intended behavior. They are not evidence that the features have been implemented.
